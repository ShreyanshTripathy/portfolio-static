Constructing Cloud Chamber with Peltier Disks

Built a cloud chamber for observing ionizing radiation using Peltier-based cooling.

This project focused on designing and testing a compact cloud chamber using Peltier disks to achieve the temperature gradient needed for particle track visualization.
